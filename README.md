# A4L Law Bridge

옵시디언(Obsidian)을 변호사의 법령·판례 지식관리 시스템으로 만드는 플러그인입니다.

- **법령 동기화** — 법제처 국가법령정보 Open API에서 법령을 조문 단위 노트로. 개정되면 알림.
- **실시간 인식** — 서면을 쓰는 동안 조문·사건번호를 인식해 관련 노트를 옆 패널에 추천.
- **판례 수집** — 대법원 판례·헌재결정례를 검색해 노트로. 참조판례 인용망 자동 수집(옵션).
- **판례 생사확인** — 이 판례를 뒤집은 후속 판결이 있는지 1차 스크리닝 (유효추정/변경의심).
- **서면 인용 점검** — 서면에 인용된 판례 전체를 한 번에 확인.
- **시점 조문** — 행위 시점에 시행 중이던 조문 버전 보기 (부칙·경과규정은 별도 확인).
- **Word 내보내기** — 위키링크를 정식 인용 표기로 풀어 초안 .docx 생성.

## 설치 (BRAT)

1. 옵시디언 커뮤니티 플러그인에서 **BRAT** 설치·활성화
2. BRAT 설정 → *Add beta plugin* → 저장소 주소 입력:
   ```
   ai4pastor/a4l-law-bridge-releases
   ```
3. 설치 후 **A4L Law Bridge** 활성화

## 시작하기 (약 30분)

1. **OC 키 발급** — [open.law.go.kr](https://open.law.go.kr)에서 OPEN API 활용신청 (무료, 승인 즉시~1일). 발급된 OC 값(통상 신청 이메일 ID 앞부분)을 플러그인 설정에 입력
2. 설정 탭 **연결 진단**이 전부 초록인지 확인 (볼트 폴더는 버튼 한 번으로 생성)
3. **법령 추가**에서 자주 쓰는 법령 검색·등록 → **동기화** → 조문 노트 생성
4. 서면·자문 노트에 조문(예: 민법 제750조)이나 대법원 사건번호를 쓰면 우측 패널에 추천이 나타납니다

## 안내

- 데스크톱 전용입니다 (Windows·macOS·Linux).
- 생사확인·시점 조문은 **1차 참고 신호**입니다 — 최종 판단은 반드시 원문으로 하세요.
- 데이터 출처: 법제처 국가법령정보 공동활용 Open API. 문서·판결문의 저작권과 이용 조건은 법제처 정책을 따릅니다.
- 소스 저장소는 비공개이며, 이 저장소는 배포(빌드 산출물) 전용입니다.
